# CODEX50: journal.json после записи

База: r14-final / CODEX49, commit 19eabff52fedcf945f9435aad7a2f411c82633eb. GUI, формы, расчёты и зависимости исходников не менялись.

После записи количество hardlink служебного журнала само по себе не останавливает readback и complete. Исключение принимается только после проверки sealed NEEDS_READBACK, точного пути журнала и ID, привязки подтверждённого плана, подготовленных и проверенных результатов, участников, candidate SHA, backup SHA, состава и SHA документов. Reparse и ошибки native-проверки пути по-прежнему останавливают операцию. План, документы, backup и любые проверки до записи сохраняют строгий safe(). Native Excel/Word readback сохранён. Причина появления исторического transient hardlink не установлена и не объявляется доказанной.

59 адресных Windows-тестов PASS. Новый test_codex50.py создаёт настоящий второй NTFS hardlink журнала: readback и complete проходят на корректном контексте; старое имя после атомарного обновления журнала содержит прежние байты, канонический журнал COMPLETE. Повреждённый seal, неверный SHA, подмена участника, неверные ID/путь/фаза, reparse и строгие prewrite/recovery-проверки дают STOP. В unit-тестах Office-граница подменена; отдельный нижеследующий frozen GUI-цикл использовал настоящий Microsoft Office. Первичная ошибка тестового fixture сохранена локально; после исправления только fixture весь адресный набор прошёл.

Восстановление рабочей тестовой операции выполнено один раз штатным прежним EXE после отдельного явного подтверждения владельца. До записи повторно сверены три current/candidate SHA, три backup/original SHA, seal и комплект. Последующих изменений не было, компенсация CODEX49 не требовалась. Фаза ROLLED_BACK, комплект сохранён в unpublished_documents этой операции. Две предыдущие операции и 96 файлов паспортов остались побайтно прежними.

Итоговый EXE CODEX50-r2 прошёл настоящий GUI DEV-цикл на отдельных копиях реальных Excel: ВОМ → Word/Excel → preview PDF → DEV-подтверждение → итоговый PDF → запись трёх участников → native readback → COMPLETE. Восемь шагов PASS, owned Office orphan=0. Сценарий: 3 марки, 3 изделия, 842,92 кг, 26,877 м², УЗК=2. Все восемь страниц предварительного PDF просмотрены; итоговый PDF имеет восемь страниц без предварительной отметки. При открытии Acrobat внешний Font Capture сообщил 0xc06d007e; страницы проверены установленным Poppler, настройки Windows и программа не менялись. После закрытия и повторного открытия того же EXE с тем же DEV-профилем нет диалога восстановления, незавершённых операций=0. Все три DEV-файла совпадают с candidate SHA, backup — с исходными SHA, VBA сохранён. Рабочие Excel во время приёмки не изменились.
