# PR8 Windows E2E — устранение четырёх блокеров

Основание: отчёт 24.10.2026, 92 PASS / 1 FAIL / 0 ERROR. Полный Office E2E остановлен до генерации пакета. Официальный реестр и первоначальные Word/Excel должны остаться неизменными.

## 1. Общая регрессия

Причина: require_akz_form_inputs() во время тестового patch(passport_app.excel.load_book) ранее импортировала production_app.templates и закрепляла mocked loader в уже загруженном модуле. Прямая зависимость real_forms от templates.TOKEN устранена; regex распознавания полей локален в real_forms. Добавлен тест, запрещающий такой импорт под mock.

**Gate:** полный набор тестов Windows за один запуск, 0 FAIL / 0 ERROR. Успешные отдельные safety-тесты не подменяют общий PASS.

## 2. Исторический АКЗ на три слоя

tools/prepare_akz_three_layer_template.py теперь требует отдельные уровни E17=1, H17=2, J17=3, исходные заполненные графы ЛКМ, партий, дат, мокрой/сухой толщины и согласованные объединения E18:G18, H18:I18, J18:K18. Только общих подписей «Слой №» и «Средняя толщина» недостаточно.

После преобразования проверяются числовые и текстовые маркеры каждого слоя, данные объекта, область печати и сохранность структуры после закрытия/повторного открытия Excel.

**Gate:** однослойный вход STOP **до** публикации нового XLSX, исходный файл сохраняет SHA. Переданный образец с тремя слоями имеет E17/H17/J17 = 1/2/3 и соответствующие три набора исходных строк; подтвердить это в Microsoft Excel на Windows и посмотреть все листы PDF.

## 3. Приложение к АКЗ

Исторический бланк имел A1:G1 заголовок, A2:G3 двухуровневую таблицу и не имел отдельного поля объекта. Конвертер вставляет одну объединённую строку A2:G2 с «Объект: {{OBJECT}}», сдвигая два уровня заголовков в строки 3–4. Динамический {{AKZ_MARKS}} будет в A5, за ним «Итого» в A6. После Excel Save/ReadOnly Open проверяются объект, маркеры, заголовок и область печати.

**Gate:** работающий генератор на копии с несколькими марками, корректные итоги C/E/G, отсутствие обрезки длинного объекта и лишних пустых страниц при распечатке.

## 4. Word

Исторические оформленные DOCX по-прежнему запрещены к использованию как пустые шаблоны. Для повторного прогона использовать только **новый проверенный ZIP** с тремя очищенными Word-формами (ВИК 2 страницы, УЗК с {{UZK_DETAILS_TABLE}}, документ о качестве 2 страницы). Формы согласовать ответственным.

При проверке в «Шаблоны объекта» выбирать распакованные DOCX именно из нового ZIP, не исходный заполненный акт и не нулевой повреждённый файл с похожим названием.

**Gate:** до генерации проверяется наличие нужных маркеров; после генерации в Word проверяются номер, реквизиты, таблицы, даты, заключения, отсутствие старых значений и верстка каждой страницы. В УЗК должны сохраняться повторяющиеся марки и все необходимые колонки.

## 5. Завершение

При всех PASS — полный Office + PDF E2E на отдельных копиях реестра и ВОМ, проверка общего PDF в порядке качество → приложение №1 → ВИК → УЗК → акт АКЗ → приложение АКЗ, имена и SHA; затем при необходимости временный EXE и frozen smoke.

Отдельные unit tests выполняются без Windows COM. Утверждение бланков, визуальная проверка Excel/Word/PDF, полный возврат после аварии и новая сборка EXE остаются **NOT_RUN** до нового отчёта. Вердикт о релизе: NO_GO до выполнения этих gates.

НЕ менять main, исходную RC3, реальные оригиналы и основной ВЗМК.xlsx. Не выполнять фактический паспорт в этих тестах. Не объединять PR без разрешения пользователя.
