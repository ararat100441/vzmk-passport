# АКЗ — мокрая и сухая толщина каждого слоя

## Согласованный объём

- 1 слой: прежние поля мокрой и сухой толщины `От/До` сохранены.
- 2 или 3 слоя: у каждого слоя вводятся два независимых измеренных
  диапазона `От/До`: мокрая и сухая толщина.
- Средняя каждого диапазона = `(От + До) / 2`.
- Для сухой толщины показываются **накопительные результаты**
  после 1, 2 и 3-го слоя. Нельзя повторно складывать уже накопительные
  результаты исторического акта.
- Сумма отдельных мокрых толщин является **арифметической суммой
  введённых значений**, не новым измерением итоговой мокрой плёнки.
- Пустые, неположительные, дублирующиеся или перевёрнутые интервалы
  запрещены при проверке. Смена исходных измерений или сумм без
  пересчёта вызывает STOP.
- Частично заполненные поля можно сохранить по команде «Назад»,
  без подтверждения фактического контроля или записи рабочих Excel.
- Для утверждённых шаблонов с токенами добавлены
  `{{LAYER_1_WET_AVG}}`, `{{LAYER_1_WET_TOTAL}}` и аналогичные
  токены слоёв 2/3; `{{WET_TOTAL}}` — арифметическая сумма.
  Уже имеющиеся `{{LAYER_n_DRY_AVG}}` остаются накопительными.

## Ограничения и границы

**Не путать** суффикс номера акта АКЗ (0–3) с числом слоёв (1–3).
Число слоёв определяется проверенной утверждённой рабочей формой.

В исторических трёхслойных Excel встречаются формулы
для суммарной мокрой толщины, вычисляющие её из накопительного сухого
покрытия и массовой/объёмной доли сухого остатка. Новая арифметическая
сумма введённых мокрых слоёв **не перезаписывает эти формулы**.
Соответствие физических величин и ячеек конкретной утверждённой формы
требует отдельной адресной приёмки.

Существующие заполненные исторические акты без `{{LAYER_n_...}}`
не становятся автоматически совместимыми шаблонами. Их копирование
вместо утверждённой очищенной формы, угадывание ячеек или перенос
исторических измерений запрещены.

Проверки даты нанесения, климата каждого слоя, состава и партий ЛКМ
**не расширялись** в этом изменении. Если утверждённая форма требует
этих сведений, её существующий отдельный контроль остаётся обязательным;
автоматическая выдача паспорта только по вводимым толщинам запрещена.
