# RC3 — общий реестр УЗК и три рабочих пути

## Ежедневные настройки

В окне «Настройки путей» остаются только рабочий реестр ВЗМК.xlsx,
общая папка Работа/Документы и один общий файл Работа/УЗК.xlsm.
Программа предлагает путь к УЗК.xlsm, если он находится рядом с реестром.
Папка очищенных технических форм является внутренней и не требует
ручного выбора при обычном оформлении.

## Первый паспорт

По номеру и серии из реестра программа ищет только папку выбранного
проекта в Работа/Документы/ПРОЕКТ/Паспорт. Первый паспорт может
находиться прямо в Паспорт либо в подпапке первого номера и даты:
1_2026 от ДД.ММ.ГГГГ, 1_1_2026 от ДД.ММ.ГГГГ и принятых старых вариантах.
Следующие паспорта и документы других проектов не используются.
Первое Приложение №1 берётся из первого паспорта с заменой всех марок
и итогов на текущую ВОМ. Заполненные исторические ВИК, УЗК, качество
и АКЗ остаются только образцами; старые результаты, даты и подписи
автоматически не переносятся. Безопасные очищенные Word/Excel
формы программа ищет во внутреннем комплекте Templates/ПРОЕКТ.
Если их нет, сообщает конкретный блокер официального выпуска.

## Один общий реестр УЗК

Файл XLSM читается только OpenPyXL без выполнения VBA и сохранений.
Лист УЗК: Заказ | Марка элемента | Кол-во (шт).
Пустое количество=1; только положительные целые. Дубликаты
с одинаковым остатком не суммируются, конфликтующие дубликаты
блокируются. Берётся только выбранный проект.
Для каждой марки текущей ВОМ: количество УЗК = минимум суммы
количеств марки в текущей ВОМ и остатка по этой марке в УЗК.xlsm.
Другие марки и заказы не объединяются. Значение показывается в форме
и проверяется при CHECK; оно недоступно ручному исправлению.
Общий УЗК.xlsm пинится SHA и не изменяется программой.

Плановое количество не является заключением ГОДЕН и не заменяет
фактический протокол УЗК. Кнопки создания/импорта CSV УЗК удалены;
текущие подтверждённые сведения о соединениях можно вводить в
той же форме программы, без отдельной дополнительной ведомости.

## Сохранение

Работа/Документы/Гараж казахстан/Паспорт/11_2026 от 25.10.2026/
Внутри: редактируемые Word/Excel и один общий PDF с тем же именем.
Используется точное написание существующей папки проекта.
Учебная копия сохраняет результаты только в учебный каталог.

## Windows-приёмка

Кодовые проверки не заменяют Native Office/EXE E2E.
Codex должен интегрировать этот PR в последний локальный worktree
с сохранением работающих генераторов, Word/Excel/PDF, защиты и recovery.
Проверка реальной ВОМ: 104 марки, 288 изделий, 15 822,14 кг,
1 021,644 м², следующий номер 11/2026.
Проверка общего УЗК.xlsm только чтением, без придуманных итогов.
Проверка трёх настроек и отсутствия отдельной кнопки Templates/CSV.
Проверка всех документов и PDF на отдельной учебной копии реестра,
включая отказ, подтверждение, hash, readback и восстановление.
Создать отдельную сборку EXE, не перезаписывая старые программы.
Без фактических протоколов и дат НЕ выпускать официальный 11/2026.
