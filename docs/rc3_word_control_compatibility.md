# RC3: Word Content Controls — проверка совместимости

Рабочая ветка: feature/rc3-word-controls; база: проверенный RC3, commit 321cae7.

## Поддержка

- Старые Word Content Controls с тегом PASSPORT_NO можно использовать как поле NUMBER **только в отдельной незаполненной форме**.
- Теги NUMBER, CONTRACT, CUSTOMER, OBJECT, CIPHER, MASS, START_DATE, END_DATE, KM, KMD_COMPANY, STEEL, VIK_DATE, UZK_DATE, AKZ_DATE, CONNECTIONS, RESPONSIBLE, EVIDENCE соответствуют одноимённым полям.
- Внутри такого Content Control должны быть пустота, стандартное отображаемое поле-подсказка Word или точный литерал {{FIELD}}. Если внутри сохранено историческое значение, приложение останавливается без замены.
- Таблицы ВИК и УЗК пока вставляются только в места, явно помеченные {{VIK_TABLE}} и {{UZK_TABLE}}. Тег Content Control вместо маркера таблицы не поддерживается.
- Проверка SDT выполняется для word/document.xml. Теги только в верхних/нижних колонтитулах не считаются подтверждёнными полями.
- Разметка и реквизиты действующих документов не утверждаются автоматически. Отдельная форма, согласование ответственного и проверка содержимого по каждому листу обязательны.

## Проверка на Windows (ещё НЕ ВЫПОЛНЕНА)

1. Создать **копию** действующего ВИК. Удалить прошлые номера, результаты, подписи и чужие реквизиты, сохранить внешний вид.
2. Для номера оставить пустое Word Content Control с тегом PASSPORT_NO; остальные поля оформить по контракту production_app/templates.py. Маркер {{VIK_TABLE}} должен быть отдельным текстовым местом вставки.
3. Проверить до ввода реальных результатов: предзаполненный номер/замеры из исторического документа приводят к STOP.
4. Прогнать замкнутый цикл на копиях реестра и ВОМ через собранный Windows EXE. Подтвердить визуально каждую страницу и данные.
5. Проверить оба сценария: успешное заполнение пустого тега и отказ при непустом старом значении. Проверить, что исходный документ не меняется (SHA-256).

Без пунктов 1–5 и утверждённых исходных форм нельзя обозначать выпуск реального комплекта как PASS.

## Проверено без Microsoft Office

tests/production/test_word_controls.py: 6 синтетических модульных тестов PASS. Это не заменяет Windows COM-интеграцию.

## Ограничение

Подлинные исторические формы ТЭМПО 1 и АКЗ отсутствуют в опубликованной ветке исходников RC3. Адаптация их реального оформления без этих файлов невозможна. Никакого автоматического переноса измерений из ранее подписанных актов не выполняется.
