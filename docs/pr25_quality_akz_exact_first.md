# PR25 — документ о качестве и АКЗ строго из первого паспорта

Пользователь прислал оригинальные файлы первого паспорта:
- 1_2026 - Документ о качестве(1).docx
- Акт № 4-2026.xlsx
- 1_2026 - Приложение к АКЗ.xlsx

Они являются образцами ОФОРМЛЕНИЯ, а не доказательством
нового фактического контроля. Эти файлы НЕ публиковались в GitHub.
Исходные оригиналы проекта открывать строго read-only.
Не добавлять окна, таблицы или новые кнопки.

Номер и все меняющиеся даты берутся ТОЛЬКО из актуального
реестра ВЗМК.xlsx, а состав/масса/площадь из текущей видимой ВОМ.
Жёлтая разметка пользователя — список замен.

## Документ о качестве — точные шесть участков

По физической структуре первого DOCX:
- Основная таблица: T0/R1 поле номера паспорта;
- T0/R16 масса изделия (сохранить «кг.» и оформление);
- T0/R18 дата окончания изготовления/отгрузки;
- T0/R50 и T0/R53: пункты 13 и 14, ссылки на два ВИК,
  УЗК и Сертификат качества АКЗ; заменять номера и даты
  раздельно (ВИК: vik_date, УЗК: uzk_date, АКЗ: akz_date);
- Вторая таблица T1/R4: дата подписи документа, связанная
  с date/END_DATE нового паспорта.

**Всё остальное неизменно**, включая дату НАЧАЛА изготовления
05.08.2026 из первого паспорта проекта, текст, реквизиты
компании, нормативную базу, имена, состав стали, краску,
сварочные материалы, размеры/оформление и места для подписи.

Программа не должна случайно заменять значение «Заказ № 1»,
так как оно НЕ выделено пользователем.

## АКЗ №0 — XLSX Акт № 4-2026

Внешнее имя исторического файла вводит в заблуждение,
но внутри E4 хранит настоящий номер 1/2026. Изменяются
в создаваемой копии только:
- E4: номер текущего паспорта + « от »;
- H4: дата АКЗ из ВЗМК.xlsx, исходный встроенный Excel формат сохраняется;
- E28: средняя измеренная СУХАЯ толщина слоя из введённого
  текущего диапазона (от+до)/2;
- E31: средняя температура поверхности;
- E32: средняя температура воздуха;
- E33: средняя влажность;
- E34: вычисленная точка росы Магнуса.

ОЧЕНЬ ВАЖНО: жёлтая E27 содержит ФОРМУЛУ =E28/0.6, а не
фактическое поле ввода. Её необходимо оставить формулой.
Остальные даты оригинала уже связаны формулами:
G8=E4; I8=H4; E22=H4-1; E30=E22; D49=H4.
Эти формулы не переписывать, Excel пересчитывает самостоятельно.
Текст, краска Pirocor, приборы, комиссии, подписи и
условия в неподсвеченных ячейках остаются из образца.
Для других вариантов АКЗ (1–3) оставить действующие
отдельные утверждённые формы, не выдавать однослойный акт за них.

## Приложение к АКЗ — XLSX

A1 — выделен жёлтым, меняются оба номера и дата АКЗ.
Таблица A2:G3 остаётся оформлением первого паспорта.
В строках A4:G(last) нужно изменить ВСЕ СЕМЬ полей:
Марка | Наименование | Количество | Масса 1 шт | Масса всего |
Площадь 1 шт | Площадь всего.

Это вытекает из зависимости от текущей ВОМ, даже если
жёлтым отмечен только заголовок. Иначе под новой маркой
останется старая масса/площадь. Число строк динамическое.
Строка «Итого» пересчитывает C/E/G, сохраняет жирный шрифт.
Повтор печати шапки только строки 2 и 3, без длинного названия.
Исходный Excel, его печать, данные и формулы не изменять.

## Реализация

- production_app/quality_from_first.py: шесть точных зон Word,
  снятие жёлтой подсветки на копии, проверка SHA оригинала;
- production_app/akz_from_first.py: read-only OOXML сигнатуры
  двух xlsx, адресная запись в копию через native Excel COM;
- production_app/office.py: маршрутизация только для точно
  идентифицированных форм первого паспорта №1/2026;
  другие формы продолжат прежнюю штатную генерацию;
- тесты синтетических форм и fake Excel COM, без реестра пользователя.

## Что НЕ разрешено

Слова «ГОДЕН», штатные ФИО и реквизиты из первого паспорта
переносятся как шаблонное оформление, но НЕ подтверждают
фактическое проведение контроля новой отгрузки.
Без текущего подтверждения официальный выпуск/изменение
реестра по-прежнему заблокирован существующим gate.
Никакого присваивания фальшивых результатов и подписей.
