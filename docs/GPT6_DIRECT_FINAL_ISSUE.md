# Прямой выпуск итогового пакета без предварительного PDF

Запрос владельца: убрать открывающееся перед выпуском PDF для ознакомления;
формировать сразу итоговый комплект.

## Поведение основной кнопки

1. «Сформировать пакет» проверяет актуальные ВОМ, ГОСТ, профиль, назначение
   АКЗ, климат и другие текущие сведения. Если они не заполнены, выдаётся
   ошибка с причиной без оформления фиктивного чернового выпуска.
2. `prepare` создаёт подготовленные Word/Excel во внутренней папке.
3. `verify(preview=False)` проверяет исходники/документы **без создания PDF
   предварительного просмотра**.
4. **Одно явное подтверждение пользователя** показывает объект, номер, дату,
   количество, массу, площадь, рабочие пути, списание УЗК и предупреждения.
   Согласие прямо означает выпуск **без просмотра предварительного PDF**.
   Отказ не запускает `confirm/release/commit` и не меняет три рабочих Excel.
5. После согласия `confirm → release` создаёт окончательные Word, Excel и
   **итоговый PDF без водяного знака**. Только после их проверки программа
   пишет три Excel с резервными копиями и делает native readback → COMPLETE.
6. По кнопке «Открыть документы» можно просмотреть подготовленные Word/Excel;
   финальный PDF доступен после завершения выпуска.

## Точность журнала

В direct-режиме `confirmation.reviewed=false` (предварительный PDF НЕ
просматривался), `confirmation.direct_issue_confirmed=true` и
`approved=true`. Нельзя записывать вымышленное `documents_reviewed=true`.
Отдельная декларация текущего контроля по-прежнему привязана к проверенному
плану и требует реального согласия. Старые PDF-preview-тесты остаются для
легаси-пути, но основная кнопка его не вызывает.

Формы ВИК/УЗК/АКЗ и расчёт остатков не изменяются. Любое реальное списание
требует подтверждения, проверок SHA, Office/readback и резервных копий.

## Приёмка до установки нового EXE

- Запустить `tests/production/test_gpt6_direct_issue.py` вместе с профильными
  тестами (включая CODEX49/CODEX50), проверить корректность данных в журнале.
- Пройти **полный** frozen GUI DEV-цикл на копиях реальных Excel с актуальным
  состоянием компенсированных операций. Проверить, что нет preview.pdf,
  автооткрытия PDF и ложной отметки о просмотре; итоговый PDF присутствует.
- Убедиться в STOP при отказе от подтверждения, повреждённых документах,
  неизвестных измерениях и дублирующемся паспорте.
- Не запускать официальный выпуск для проверки. Незавершённые операции
  рабочих Excel сначала разрешить отдельно с явного согласия владельца.
