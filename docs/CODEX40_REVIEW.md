# CODEX40 / r13: проверка B по текущей ВОМ

В r12 посторонние некорректные B блокировали исправную текущую отгрузку, а shipment_candidate повторно останавливался при расчёте их остатков. В r13 обязательная проверка B и достаточности остатка относится ко всем маркам текущей ВОМ. Остальные ошибки B возвращаются как stock_warnings с точной строкой, исходным B, исторической отгрузкой и причиной. GUI показывает их количество в журнале и перед подтверждением без новых кнопок.

История F+ и её соответствие подтверждённым паспортам по всем маркам остаются обязательными. Никакой ошибки истории не переводится в предупреждение B. Создание кандидата сохраняет прежние B/F+, добавляет новый паспортный столбец и пересчитывает E. Отрицательные и дробные остатки остаются числовыми. Отсутствующее или нечисловое B даёт явное «НЕИЗВЕСТНО: проверьте B» вместо нуля. Строгий режим update_balance по умолчанию сохранён для прежних вызовов; shipment_candidate применяет его ко всем текущим маркам.

Изменены три runtime-модуля: catalog_ledger.py, coordinated.py, gui.py. Формы ВИК/АКЗ и набор кнопок не менялись. Старый тест о блокировке постороннего B обновлён под новый контракт. Шесть новых тестов проверяют предупреждения, сохранность кандидата, блокировки текущей ВОМ и повреждённой истории других марок. Общая регрессия: 653 теста без ошибок и пропусков.

Frozen EXE прошёл GUI → Word/Excel → предварительный PDF → DEV-подтверждение → запись трёх DEV-файлов → native readback → COMPLETE на точных копиях настоящих исходников. Проектные B и УЗК не подменялись. Все 84 проблемные строки остались в справочнике, все прежние B/F+ сохранены, УЗК.xlsm побайтово прежний. Кандидат отдельно проверен Excel ReadOnly: 44 отрицательных остатка не маскируются. Источники и рабочие файлы не исправлялись.

Оба PDF содержат 7 страниц без УЗК, с полным ВИК и АКЗ. Основное содержимое всех страниц совпадает по геометрии глифов и пикселям. На странице АКЗ отличается только последовательность извлечения текста из PDF, а не его расположение/изображение. Внешняя ошибка Adobe Font Capture сохраняется; PDF проверялись через Poppler. Microsoft Office и принятые формы не исправлялись.

Frozen recovery проверен на отдельных копиях байтов фактической транзакции: смешанное исходное/кандидатное состояние, состояние с опубликованной папкой, безопасный повтор, запрет всех замен при внешнем изменении. Исходные SHA трёх файлов восстановлены. Это диагностические состояния, не реальные аварийные завершения процесса.

Рабочие Excel, история, r12 и main сохранены. Официального выпуска не было. Это ограниченная DEV-приёмка конкретной отгрузки; общий PRODUCTION READY не присвоен. Реальные Excel/DOCX/PDF, EXE, настройки и частные журналы не публикуются.

База: r12 1bc03df2970a1421ef9c41313e864551e5ee7927. Review-ветка codex/review-production-r13-codex40. Четыре исторических runtime-модуля сохраняют прежнее обезличивание; 110/114 входов сборки совпадают с публичным снимком, все три изменённых runtime-модуля совпадают побайтово. Полная воспроизводимость EXE только из публичного снимка не заявляется.
