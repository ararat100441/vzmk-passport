ВЗМК — Паспортизация 1.0.0 — r7 / CODEX34

НАЧАТЬ ЗДЕСЬ
1. Откройте EXE. Проверьте видимые рабочие пути, выберите объект,
исходный паспорт, «Новый паспорт», номер и дату окончания/отгрузки.
2. Нажмите «Отгрузочная ВОМ». Выделите таблицу в Excel, Ctrl+C,
затем Ctrl+V в окне ВОМ. Проверьте строки и итоги, нажмите ОК.
Повторная вставка полностью заменяет прежнюю таблицу. «Удалить строку»
и двойной щелчок для редактирования сохранены; добавление отдельной
пустой строки не требуется.
Допустимы 5, 6 и 7 столбцов; однозначный столбец «Лист №» отбрасывается.
Площадь можно ввести позже. Для полного пакета она необходима;
неизвестная площадь никогда не считается нулевой.
3. Откройте «Фактические результаты». Проверьте профили, ГОСТ,
назначения АКЗ и план УЗК. ГОСТ выбирается двойным щелчком.
Для каждого профиля автоматически показан первый допустимый ГОСТ
в порядке строк утверждённого Профили.xlsx. Это значение по умолчанию;
оно не удостоверяет соответствие проекту. При ручной замене выберите
общий стандарт профиля либо индивидуальное исключение марки.
Подтверждённый выбор сохраняется по объекту. Изменение справочника,
сделавшее сохранённый стандарт недопустимым, вызывает явную ошибку.
Редактирование ГОСТ доступно только в фактических результатах.
Введите текущие диапазоны климата, мокрой и сухой толщины АКЗ.
«Назад» сохраняет даже частичный ввод в текущей заявке.
Замена только ВОМ сохраняет введённые диапазоны, заменяет состав
марок и пересчитывает количества УЗК. Нулевой план остаётся нулевым.
Нажмите «Сформировать пакет» и просмотрите ВСЕ страницы PDF.

Единственное подтверждение после PDF удостоверяет текущий выполненный
ВИК/УЗК, достоверность введённых измерений АКЗ, действующие формы,
полномочия владельца и просмотр пакета. Старый образец и расчёт из ВОМ
сами по себе не подтверждают новый контроль. Не подтверждайте выпуск,
если контроль не выполнен или факты неизвестны. Заявление сохраняется
в журнале, привязанном к проверенному пакету; протоколы не создаются.
При отмене три рабочих Excel-файла не меняются.

Все формы берутся из явно выбранного исходного паспорта. Отсутствующая
или несовместимая форма останавливает соответствующую подготовку с
указанием причины. Начало изготовления всегда из первого паспорта
объекта в реестре; дата окончания — указанная дата отгрузки.
Постоянное содержание образцов сохраняется, согласованные поля и
таблицы марок меняются. Два ВИК имеют номера N и N-1. Для каждого
АКЗ создаётся собственная пара «акт → приложение».

Окончательные Word/Excel и единый PDF находятся в папке паспорта.
PDF называется как папка. Порядок: качество, Приложение №1, оба ВИК,
УЗК, акт и приложение каждого применимого АКЗ. Временный PDF помечен
как предварительный, не выпущенный. Автоматической печати нет.

После подтверждения согласованно обновляются ВЗМК.xlsx, справочник
отгрузок и общий УЗК.xlsm: резервные копии, запись, readback и журнал.
При сбое используйте «Настройки путей → Восстановление после сбоя».
Не повторяйте выпуск при неизвестном состоянии операции.

В настройках задаются три рабочих источника: ВЗМК.xlsx, общая папка
документов и УЗК.xlsm. Справочник объекта находится автоматически.
Новое имя: «Справочник Марок <Название проекта>.xlsx»; старое имя
«Справочник марок.xlsx» поддерживается. При двух именах явно выберите
действующий файл. Создание справочника создаёт только файл в уже
существующей папке. Первый паспорт оформляет владелец самостоятельно.
Общее количество в столбце B вводится владельцем; неизвестный остаток
не равен нулю. Назначения отсутствующим маркам программа не выдумывает.

Нужны Microsoft Word и Excel. Python и Codex для запуска не нужны.
Храните EXE, Templates и _internal вместе. Старые версии не заменяются.
Статус конкретной поставки и границы проверок — в ОТЧЁТ_CODEX34.md.
Количество пройденных тестов не означает окончательный PRODUCTION READY.
