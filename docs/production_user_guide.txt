ВЗМК — Паспортизация — RC3 Sources test (PR19)

В «Настройки путей» выбираются только три источника: рабочий реестр
ВЗМК.xlsx, общая папка Работа/Документы и общий Работа/УЗК.xlsm.
Первый паспорт и справочник выбранного проекта находятся автоматически.
Очищенные бланки берутся из внутренней папки Templates программы.
Новый паспорт сохраняется рядом с первым в существующей папке проекта:
Работа/Документы/Гараж казахстан/Паспорт/11_2026 от ДД.ММ.ГГГГ/.

1. Выберите объект, отметьте «Новый паспорт» и выберите ВОМ.
Программа покажет следующий номер, количество марок и изделий, массу
и площадь. Активные реестр и режим видны на главном экране.

2. Откройте «Фактические результаты». Справочник выбранного проекта
подключается автоматически: подставляются только имеющиеся назначения.
Пустые профиль, краска и № АКЗ остаются пустыми. Результаты ВИК/УЗК,
первичные протоколы и фактические измерения новой отгрузки не копируются
из первого паспорта. Для каждого используемого АКЗ приложите его протокол.
Количество УЗК вычислено по общему УЗК.xlsm и текущей ВОМ; оно не
редактируется вручную и не подтверждает заключение «ГОДЕН».
XLSM читается без запуска VBA и не изменяется. CSV не требуется:
реальные сведения о соединениях можно внести в этом же окне.
Климат и сухая толщина вводятся текущими диапазонами От/До; середина
рассчитывается как (От+До)/2. Это середина диапазона, не статистическая
средняя. Для Казахстана подключена отдельная однослойная форма АКЗ №0.
Новый очищенный бланк необходимо утвердить перед рабочим применением.

Верхней строки ответственного и дат нет. Даты существующего паспорта
берутся из его строки. Даты нового паспорта вычисляются только в частной
копии реестра из подтверждённых формул. При фиксированной старой дате
программа назовёт поле и остановит выпуск. Не меняйте рабочий реестр
ради обхода сообщения. Предложенная дата паспорта видна при подтверждении.

3. Нажмите «Сформировать пакет». Программа проверит данные, сформирует
Word/Excel и предварительный PDF, затем откроет его для просмотра.
Просмотрите все страницы. Одно подтверждение показывает объект, номер,
дату, реестр и папку результата. После «Нет» реестр не меняется; кнопка
«Просмотреть и подтвердить» позволяет вернуться к тому же комплекту.
После изменения исходных данных формируется новая проверенная заявка.

После подтверждения программа создаёт итоговый PDF рядом с Word/Excel,
выполняет резервное копирование, запись, readback и завершение операции.
PDF называется как папка паспорта. Порядок: качество, Приложение №1, ВИК,
УЗК, затем акт и приложение каждого применимого АКЗ. Печать автоматически
не запускается. Диагностика и восстановление сохранены в прежних действиях.

Реестр 11/2026 сейчас имеет фиксированную дату начала первого паспорта;
для новой отгрузки нужен подтверждённый источник этой даты (H353).
Из справочника загружены профили 55 из 104 марок; профили остальных
49, краска и назначения АКЗ всех 104 марок отсутствуют. Нужны реальные
протоколы, даты и измерения. Плановый УЗК этой ВОМ — 33 изделия по
четырём маркам. Учебные примеры не подтверждают реальный контроль.

При Windows-проверке внешнего Adobe Acrobat появилось сообщение
«Font Capture», код 0xc06d007e. Файлы PDF проверены независимо: все страницы
читаются и совпадают с проверенным черновиком. Ошибка просмотрщика
зафиксирована в отчёте; при её появлении откройте PDF другим установленным
просмотрщиком. Рабочие документы и настройки Windows ради обхода не меняйте.

Требуются установленные Microsoft Word и Excel. Python и Codex не нужны.
EXE и _internal храните вместе. Настройки RC3 Sources test изолированы от
предыдущих программ; старые EXE и ярлыки не заменяются.
