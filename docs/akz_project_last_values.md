# АКЗ — климат на день, диапазоны 3 слоёв и настройки по объекту

Решение пользователя от 19.10.2026. Состояние: исходники в draft-ветке; нативная проверка Microsoft Excel и выпуск окончательной 1.0.0 ещё не выполнены.

## Как должны работать значения

- Каждый объект из реестра имеет **свои** последние показатели, без общего глобального набора для разных объектов.
- Внутри одного АКЗ (вариант 0/1/2/3), если три слоя оформляются с одними климатическими условиями в один день, задаётся **один набор** температуры воздуха, температуры поверхности, относительной влажности и точки росы. В шаблоне этот набор можно повторить для каждого слоя. Если нанесение происходит в разные дни, показатели должны быть заново подтверждены для каждого дня; один набор не свидетельствует о замерах в другие дни.
- Толщина задаётся **отдельным диапазоном для каждого из трёх слоёв**: минимальная и максимальная, в мкм. Никаких придуманных значений по умолчанию нет.
- Контроль ведётся по **фактически измеренной средней толщине сухого покрытия** после каждого слоя, нарастающим итогом, как в историческом бланке. Для слоя №1 средняя после первого слоя; для №2 средняя после первых двух; для №3 средняя после всех трёх. Средняя после каждого слоя должна входить в накопленный диапазон (сумма нижних границ ... сумма верхних). Это не среднее арифметическое двух границ диапазона.
- Слои 1/2/3 не смешиваются с номерами вариантов АКЗ 0/1/2/3. Вариант — отдельный акт/сертификат; слой — стадия покрытия.
- Показатели прошлого паспорта — только **предзаполнение интерфейса**. В предыдущем паспорте могут быть другие партии, фактические толщины, результаты или даты. Они не копируются в новые протоколы и акты.

## В интерфейсе

В окне «Фактические результаты» по каждому используемому варианту АКЗ есть:
- строка общего климата (воздух, поверхность, влажность, роса);
- существующие отдельные поля для фактической средней толщины, материала и первичного послойного протокола;
- три строки «Слой 1/2/3», каждая с полями «От», «До» (допустимый диапазон слоя) и «Средняя сухая после слоя» (фактически измеренная средняя нарастающим итогом). Индивидуальные минимальные и максимальные замеры не требуются.

При новом выборе проекта текущие факты очищаются. Система читает **только** его локальную историю. При возврате к прежнему проекту подставляются его последние данные. Показатели привязаны также к выбранному варианту АКЗ, чтобы разные акты/даты не смешивались.

## Когда сохраняется последнее

Только после успешного рабочего цикла complete => ГОТОВО для фактического паспорта.
Сохраняются: проект, вариант АКЗ, четыре климатических показателя и три диапазона толщины; дата прежнего АКЗ — как справочная метка.

НЕ сохраняются и НЕ используются как будущие факты: старые протоколы, средние фактические толщины после каждого слоя, материал конкретной партии, сотрудники, подписи и утверждения.

Учебный режим ничего не записывает в историю реальных проектов и не подставляет их параметры.

На **первом использовании** проекта, если программа ранее не оформляла по нему комплект, поля будут пустыми. Ввести и подтвердить их должен ответственный инженер. После первого успешного выпуска программа предложит эти значения в следующем паспорте.

Файл удобства:
%LOCALAPPDATA%\VZMKPassportProduction\akz_presets.json

Этот файл не изменяет рабочий реестр и не является первичным источником результатов контроля. При повреждении он не используется и не блокирует ручной ввод.

## Правила диапазона

Для одного 3-слойного акта все слои должны быть пронумерованы 1/2/3, без повторов. Каждый минимум и максимум — положительное число, минимум не больше максимума. Пример структуры, **не реальные нормативы/замеры**:
- слой 1: от 80 до 120 мкм;
- слой 2: от 90 до 140 мкм;
- слой 3: от 100 до 160 мкм.

Это пример допустимого формата, а не рекомендуемые значения для ВЗМК.

## Excel шаблон

Для утверждённого трёхслойного акта предусмотрены поля:
- общие: {{AIR}}, {{SURFACE}}, {{HUMIDITY}}, {{DEW}}, повторяемые для каждого слоя;
- диапазон слоя №X: {{LAYER_X_RANGE}} или пара {{LAYER_X_MIN}} и {{LAYER_X_MAX}}, X=1,2,3.
- подтверждённая средняя толщина сухого покрытия после слоя №X: {{LAYER_X_DRY_AVG}} (числовая ячейка). Три поля обязательны для нового трёхслойного бланка. Средняя не вычисляется из границ диапазона и не подставляется из прошлого паспорта.

Чистая ячейка с числовым полем записывается в Excel как число. Текст «от ... до ...» остаётся текстом, его нельзя ставить в формулу вместо числового значения.

**Важно:** старый трёхслойный акт Excel содержит также фактические послойные замеры мокрой/сухой плёнки, даты, партии ЛКМ, приборы и подписантов. Одни климат и диапазоны этих полей не заполняют. Сборка 1.0.0 с официальным трёхслойным актом пока не принята.
