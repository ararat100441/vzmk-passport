Повторное использование папки запрещено.

`python -B stage7.py preview <точный manifest>` проверяет источники и receipts. `python -B stage7.py generate <manifest> --output DEV/Stage7_Выход/<новая папка> --confirm-test` создаёт только качество из проверенного manifest. При изменении входов или кода старый preview/manifest недействителен; требуется новая проверка checkpoint и новый запуск, а не редактирование SHA.

Stage 7 operation receipt — новый локальный журнал реального вызова, не старый Stage 5 receipt. START, RESULT, VALIDATION и receipt связаны одним operation_id / assembly_run_id и SHA. Original inputs/code удерживаются read-only Windows handles; записи запрещены. Receipt появляется после успешного вызова и native Word проверки нового DOCX. Ошибка оставляет FAILURE, без успешного receipt; такой output исключён из выбранного комплекта. SHA-цепочка предназначена для локального аудита, не является электронной подписью.

УЗК — SAMPLE_ONLY, ДНО/годен являются примером. АКЗ №0 — TEST, только 3 назначенные марки / 3 изделия; замеры отсутствуют. АКЗ №1/2/3 исключены. ВИК — DEV/TEST, две записи одного нового DOCX; принятый Stage 2 сохраняет исходную форму, а TEST-статус задаётся изолированным запуском, manifest и документом о качестве. ВИК отдельно не предназначен для официальной выдачи.
