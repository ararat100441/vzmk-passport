ВЗМК — автоматизация паспортов качества. Этап 1

Запуск на этом компьютере
В PowerShell из папки Pasport:
  powershell -NoProfile -ExecutionPolicy Bypass -File .\Запустить.ps1

Или напрямую:
  & "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" .\main.py

Используются уже установленные Python 3.12, openpyxl, pywin32 и Microsoft Excel.
Новых зависимостей не устанавливалось. requirements.txt описывает зависимости программы.
Для другой установки нужны Python с Tk, openpyxl, pywin32 и установленный Excel.

Работа
1. Выберите проект. Список читается из непустых значений «Примечание» реестра.
2. Выберите текущий отгрузочный ВОМ (.xlsx).
3. Нажмите «Проверить». Это чтение и проверка доступности; паспорт не создаётся.
4. При нуле ошибок нажмите «Сформировать блок 1».
   Кнопка становится доступна только после успешной проверки.

settings.json
Пути документов и реестра заданы относительно settings.json.
Для «Гараж Казахстан» настроены фактическая папка «Паспорт» и первое приложение.
Если название проекта точно соответствует папке в Документах, программа ищет
его папку «Паспорт» и единственный шаблон, совпадающий с первым номером, датой и объектом.
Для исторических проектов, переименованных папок и названий со знаком / нужна
явная запись projects с passport_root и template (пути относительно documents_root).
По похожим названиям папки не выбираются. При неоднозначности формирование запрещено.
Номера с дополнительными частями, буквами, нулём, дубли или отсутствие единственного
паспорта 1/год дают понятную ошибку проверки. Такие номера не переинтерпретируются.

Соединения
Источник — «Наименование марки» текущего ВОМ. Непустые значения обрезаются по краям,
уникальные значения сохраняют порядок первого появления и исходное написание,
затем объединяются через запятую и пробел. Регистр не меняется.
Строки самого приложения сохраняются по порядку, повторяющиеся марки не объединяются.
Общие масса и площадь берутся из соответствующих исходных столбцов, а не вычисляются
заново умножением округлённых значений 1 шт. При отсутствии строки Итого суммы
получаются сложением исходных строк; если Итого присутствует, выполняется сверка.
Формулы ВОМ должны иметь сохранённые числовые результаты Excel.

Запись
Первый паспорт и ВОМ никогда не сохраняются программой.
До изменения создаётся точная резервная копия реестра в «Резервные копии ВЗМК» рядом с ним.
Реестр редактируется в отдельной временной книге через Excel COM. Новая строка
в таблице копируется из ПЕРВОГО паспорта. Изменяются номер, масса, дата окончания
и соединения. Остальные формулы сохраняются и пересчитываются в Excel.
В новом паспорте создаётся только «Приложение № 1.xlsx» с префиксом текущего номера.
Папка называется по номеру и дате окончания новой строки.

Во время работы файлы блокируются от параллельного чтения/записи.
Реестр заменяется через Windows ReplaceFileW с сохранением его метаданных и ACL.
После этого временная папка приложения переименовывается в окончательную.
Две отдельные файловые сущности нельзя опубликовать единой атомарной операцией.
Ход записывается в .pasport-transactions рядом с реестром. Если процесс был прерван
или публикация после записи реестра не завершена, следующий запуск блокирует повтор
и сообщает журнал и резервную копию. Автоматического восстановления/перезаписи нет.
Временные материалы не удаляются, чтобы сохранить возможность независимой проверки.
Не удаляйте журнал незавершённой операции без выяснения фактического состояния.

Проверка на копиях
  & "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" .\tests\validate_real.py
Тест сам создаёт новые копии реальных файлов в validation и не пишет в рабочий реестр.
Дополнительные ВОМ на 7 и 100 строк получаются сокращением/повторением реальных строк.
PNG отрисовываются из сохранённых XLSX через bundled artifact-tool, без PDF.
Для повторной проверки логики без повторной отрисовки:
  $env:PASSPORT_NO_PREVIEWS = '1'
  & "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" .\tests\validate_real.py
  Remove-Item Env:PASSPORT_NO_PREVIEWS
GUI smoke на новых копиях:
  & "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" .\tests\gui_smoke.py

Границы
Реализован только Этап 1. ВИК, УЗК, АКЗ, их документы и другие следующие этапы
не создаются. Существующие формулы дат в реестре сохраняются как часть копирования строки.
PDF и exe-сборка не создаются.
