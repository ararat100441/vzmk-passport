# ВЗМК Паспортизация r9 CODEX36

Снимок актуальных локальных исходников r9 для независимого аудита. Основан на точных локальных входах сборки r8 CODEX35. Ветка review/production-r9-codex36 не предназначена для merge в main. PRODUCTION READY не присвоен; официальный выпуск с реальными файлами запрещён.

## Адресные изменения

- В выходной копии УЗК сокращены только пустые интервалы и межабзацные отступы. Размеры шрифтов, поля, ширины столбцов, текст и реквизиты сохранены. Для четырёх марок таблица и исполнитель помещаются на одном альбомном листе.
- Проверка нативной пагинации PDF удерживает последнюю марку вместе с полным блоком исполнителя. Если Word разрывает группу несмотря на KeepWithNext, в несохраняемом буфере экспорта устанавливается разрыв перед последней маркой и результат повторно проверяется.
- Опечатка мГц исправляется на МГц в заголовке выходной копии УЗК, включая текст, разделённый на runs.
- Предварительный PDF получает маркировку на каждой странице после пагинации. Word/Excel открываются только для чтения; исходные файлы не сохраняются. Итоговый PDF формируется без маркировки.
- Статическое значение общей толщины в исходной форме АКЗ сохранено: оно не является переменным полем измерений и не содержит формулы. Измеренные мокрая и сухая толщины проверяются отдельно. Формы ВИК не менялись.

## Проверки и соответствие сборке

Доказательства и ограничения: review/CODEX36_SUMMARY.md. Манифест локальных входов EXE: review/BUILD_INPUTS_R9.json. Манифест опубликованных исходников: review/SOURCE_MANIFEST.json. Он содержит SHA локальной и опубликованной версии каждого файла и причины обезличивания.

Четыре исторических runtime-модуля обезличены для исключения персональных данных и реквизитов формы. Они отличаются от реальных входов EXE, поэтому публичный снимок не является полностью побайтово воспроизводимой поставкой. Три исправленных runtime-модуля CODEX36 опубликованы без изменений.

Нужны Windows, Python 3.12 с Tkinter, Microsoft Word/Excel, зависимости requirements.txt и requirements_stage5.txt, PyInstaller/olefile/psutil. Для Unicode-маркировки PDF добавлен ReportLab 4.x (проверена 4.4.9) и используется системный Arial. Запуск: production.py. Сборка: python -B tests/production/build.py --name reviewr9.

Рабочие документы, справочники, ВОМ, настройки, PDF и EXE не публикуются. Нативные проверки требуют приватных утверждённых образцов; их отсутствие после клонирования не считается PASS.
