# ВЗМК Паспортизация r10 CODEX37

Актуальные обезличенные исходники для независимого аудита. База r9: ff63c588d99554a46513de546bb8faffb9fe4216. Ветка review/production-r10-codex37. Main и прежняя поставка r9 не изменяются. Реальный выпуск запрещён. PRODUCTION READY не присвоен.

Изменены только два runtime-модуля. В предварительном Word PDF временная маркировка удаляется из отдельной XML-копии тем же способом, что при подготовке итогового документа; Word Range.Delete больше не влияет на расположение таблиц. Надпись добавляется после пагинации на каждой странице PDF в верхнем свободном поле. В Приложении №1 только итоговая ячейка площади получает три десятичных знака; исходные числа и SUM не меняются.

Точка входа production.py, обычный GUI production_app/gui.py. Windows, Python 3.12, Microsoft Word и Excel, зависимости requirements.txt и requirements_stage5.txt. Сборка: python -B tests/production/build.py --name reviewr10. ReportLab 4.x (испытана 4.4.9), системный Arial.

Результаты и ограничения: review/CODEX37_SUMMARY.md. Точные локальные SHA входов EXE: review/BUILD_INPUTS_R10.json. Обезличивание и обе SHA каждого исходника: review/SOURCE_MANIFEST.json. Четыре исторических runtime-файла сохраняют прежнее обезличивание и отличаются от локальной сборки; воспроизведение EXE только из публичного снимка побайтово не заявляется. Два исправленных runtime-модуля и новые тесты опубликованы без редактирования.

Реальные документы, ВОМ, справочники, настройки пользователя, PDF и EXE не публикуются. Нативные тесты требуют приватных утверждённых образцов. Синтетические DEV-результаты не подтверждают реальный контроль. Материалы CODEX36 и BUILD_INPUTS_R9 в review относятся к исторической базе r9.
