# ВЗМК Паспортизация r11 / CODEX38

Review-ветка codex/review-production-r11-codex38. База — r10 f38b51f542117927cf6a4139e9195c2382c20170. Main не изменяется. PRODUCTION READY не присвоен. Только независимый аудит и DEV-проверки.

Текущее проектное количество читается из B действующего справочника. Увеличение и уменьшение не требуют миграции. Отрицательный остаток, нецелое количество, изменение прежних отгрузок или превышение остатка останавливают проверку.

Перемещение исторического приложения и изменение XLSX-байтов обрабатываются отдельно. Единственный источник внутри папки паспортов проекта проверяется по номеру, дате, объекту, маркам, количеству и массе с реестром. Проверенная привязка и аудит старой привязки попадают в кандидат справочника. Исходный XLSX не сохраняется. Штатный coordinated commit сохраняет проверенную резервную копию прежнего справочника до замены.

Описание и ограничения: docs/CODEX38_REVIEW.md. Результаты: review/CODEX38_SUMMARY.md. Запуск: production.py. Сборка: python -B tests/production/build.py --name reviewr11. Windows, Python 3.12, Microsoft Word/Excel; зависимости requirements.txt и requirements_stage5.txt, PyInstaller, pywin32, pypdf, ReportLab 4.x.

Четыре исторических runtime-модуля сохраняют прежнее обезличивание. Их отличия от локальных входов EXE явно указаны в review/SOURCE_MANIFEST.json. Новое исправление и тесты опубликованы побайтово. Полная воспроизводимость EXE из одного публичного снимка не заявляется. Реальные XLSX, DOCX, настройки, PDF, EXE и частные журналы не публикуются.
