## Разработчику

Нужны Windows, Python 3.12 с Tkinter, настольные Word/Excel с COM.
Установите зависимости из `requirements.txt` и `requirements_stage5.txt`, дополнительно `pywin32`, `python-docx`, `lxml`, `pypdf`, `olefile`, `pyinstaller`, `psutil` по импорту существующих модулей.
Запуск: `py -3.12 -B production.py`.
Утверждённый сборщик: `py -3.12 -B tests/production/build.py --name reviewr5` (в этой публикации сборка НЕ запускалась).
Рабочие данные и утверждённые формы необходимо подключить отдельно. Ни реестры, ни ВОМ, ни паспорта/сертификаты, ни профильная Excel-база, ни служебные Office-шаблоны не включены. Нативные проверки, которым они нужны, нельзя считать пройденными только после клонирования.

Предыдущая полная Windows-регрессия CODEX31: 542 PASS / 0 FAIL / 0 ERROR. Перечень модулей и число тестов — `review/REGRESSION_SUMMARY.json`. При публикации тесты и сборка не повторялись. Синтаксис публикуемых Python-файлов проверен без запуска.
