# ВЗМК — Паспортизация 1.0.0 — r7 / CODEX34

Актуальный снимок локальной r7 для независимого аудита. Точка входа: `production.py`, рабочий GUI: `production_app/gui.py`. Отдельный корневой коммит исключает прежнюю историю с производственными документами; ветка не предназначена для merge в main.

## Исправления

Первый допустимый ГОСТ выбирается в физическом порядке строк утверждённого справочника. Подтверждённый общий выбор хранится по объекту/профилю, исключение — по марке. Смена источника не скрывается. ГОСТ редактируется только в фактических результатах. Повторная вставка ВОМ заменяет таблицу целиком; кнопка удаления строки сохранена. Состав фактических марок и нулевые количества УЗК синхронизируются с текущими источниками, а диапазоны климата сохраняются. Сообщения о климате называют видимое поле и вариант АКЗ. Windows-проверка ссылки использует сведения дескриптора, сохраняя запрет hardlink/reparse. Word запускается отдельным проверяемым процессом с одним ключом /a; диагностика сохраняет классы окон и текст диалога запуска. Исправлен порядок освобождения собственного Popen-дескриптора.

## Сборка и соответствие

Нужны Windows, Python 3.12 с Tkinter, настольные Word/Excel. Зависимости: `requirements.txt`, `requirements_stage5.txt`, `pywin32`, `python-docx`, `lxml`, `pypdf`, `olefile`, `pyinstaller`, `psutil`. Запуск: `py -3.12 -B production.py`. Сборка: `py -3.12 -B tests/production/build.py --name reviewr7`.

Рабочие данные, утверждённые формы и бинарные фикстуры не включены. Их отсутствие не означает успешное прохождение нативных тестов после клонирования.

`review/BUILD_INPUTS_R7.json` содержит SHA всех входов фактической локальной сборки. В публикуемом снимке разрешённо обезличены ФИО, отдельные фамилии, приватное имя Windows-пользователя, договор и шифр исторической формы. **Такие файлы отличаются от входов EXE**; точный список, признак участия в сборке и SHA до/после находятся в `review/SOURCE_MANIFEST.json`. Снимок не выдаётся за полностью побайтово идентичный EXE. Обезличивание ограничено литералами. В четырёх входах сборки оно затрагивает строки сопоставления с историческими формами; публичная копия с реальными формами не валидировалась. Полностью воспроизвести локальный EXE из обезличенной копии нельзя. Точный исходный снимок остаётся у владельца локально.

## Статус

Статус поставки и границы фактических проверок — `review/CODEX34_SUMMARY.md`. Регрессия не заменяет приёмку собранного EXE. Синтетические DEV-измерения не удостоверяют реальный контроль. Окончательный PRODUCTION READY не присваивается. Ветка опубликована для независимого аудита; main, merge и deploy не затронуты.
