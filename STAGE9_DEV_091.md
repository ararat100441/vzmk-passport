## Рабочий порядок

1. Открыть EXE. Создать новый DEV-стенд, указав исходный каталог Pasport. Импорт читает источники и создаёт отдельную копию с новым идентификатором.
2. Выбрать «Гараж Казахстан», существующий 9/2026 либо новый паспорт, исходную отгрузочную ВОМ и необходимые варианты АКЗ. Для проверенного сценария выбран АКЗ №0. Пустое значение отличается от 0.
3. Выполнить проверку. Сверить состав, видимые строки, количество, массу, площадь и УЗК. Смена выбора требует новой проверки.
4. Подтвердить TEST-формирование. Документ о качестве создаётся последним. УЗК остаётся SAMPLE_ONLY. Посмотреть Word/Excel через кнопку открытия документов; открываются отдельные собственные экземпляры read-only.
5. Проверить полноту. Файлы и диагностика находятся в отдельном DEV-стенде под `%LOCALAPPDATA%/VZMKPassport/workspaces`; сборка не содержит пользовательских реестров и паспортов.
6. Для тестирования закрытия использовать вкладку Stage 8 и отдельную искусственную копию 8001/2099. Подтверждение закрытия применяется только к этому TEST. Повторное закрытие не списывает повторно.
7. При незавершённой операции сначала проверить журнал/recovery. Восстановление из backup требует отдельного явного TEST-подтверждения, не закрывает паспорт и не выполняет повторное списание. При конфликте SHA, lock, backup или identity — остановка без опасной записи.
8. Дождаться окончания операции и закрыть программу. Она закрывает свои просмотровые Word/Excel; пользовательские экземпляры не используются.

Официальное закрытие 9/2026 и официальная выдача TEST/SAMPLE_ONLY запрещены. Реальные результаты контроля, измерения и назначения не подменяются тестовыми. Для других проектов необходима отдельная принятая привязка шаблонов. Реальные АКЗ №1–3 текущей отгрузки не подтверждены.
