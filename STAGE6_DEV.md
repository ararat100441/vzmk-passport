# Этап 6 Part 1 — DEV TEST АКЗ №0

Запуск: `Запустить Этап 6 DEV.cmd`. Требуются существующие Python 3.12,
openpyxl, pywin32, Microsoft Excel. Используется только DEV/ВЗМК_DEV.xlsx.
Этапы 1–5 не изменены. Настройки production не загружаются.

Выберите проект, существующий паспорт DEV, конкретную ВОМ XLS/XLSX и каталог
из DEV/Stage6_Fixtures. Выбор файла означает явное указание отгрузки данного
preview; номер не выводится из имени ВОМ. Проверка показывает видимые строки,
выбранные назначения 0, пропуски, другие варианты, итоги и дату из «Дата Акз».
Генерация доступна после проверки; изменение выбора сбрасывает preview,
изменение файлов вызывает STOP при генерации.

Пара шаблонов фиксирована точными проектными путями и SHA. Part 1 поддерживает
до 17 выбранных строк исходной формы; превышение — явный STOP без обрезания.
Одинаковые марки не объединяются. Отсутствие записи и пустой № АКЗ показываются
как отсутствие назначения. Назначения 1/2/3 не генерируются.

Числа берутся только из выбранной видимой ВОМ. Пустая/нулевая площадь и
неподтверждённое соответствие total = unit × quantity останавливают выбранную
группу. Допуск 1e-8 служит только для погрешности передачи Excel double,
округление бизнес-данных не применяется. Справочник не даёт массу или площадь.
Формат вывода чисел сохраняет десятичную точность выбранных значений ВОМ,
чтобы исходный двухзначный формат исторического приложения не скрывал площадь.

Результат — папка COMPLETE_TEST_PAIR внутри DEV/Stage6_Выход. Оба файла
публикуются одним переименованием временной папки. Существующий результат
не перезаписывается; ошибка второго файла удаляет только временную пару.
PAIR.json содержит единый ACT-ID, номер, дату и SHA обоих файлов.

Фактические контрольные поля очищены от истории и отмечены «НЕТ ДАННЫХ / ТЕСТ».
Pirocor Protect 057, RAL 7004, один слой, требуемые 80 мкм сохраняются из формы.
Климат — одна запись ClimateDay на календарную дату; повтор с другими значениями
вызывает конфликт. По умолчанию MISSING. TEST-набор требует полной записи и
Ts >= Td+3. Формула Td не выбирается и не вычисляется. Официальная выдача STOP.

SYNTHETIC требует изолированную ВОМ в Stage6_Fixtures и отдельный номер
SYNTHETIC-TEST. Такие числа не оформляются как реальные данные паспорта.
Реальные каталоги/ВОМ/формы, DEV-реестры не сохраняются.

PDF, EXE, deployment, АКЗ-1/-2/-3 и Stage 7 отсутствуют.
