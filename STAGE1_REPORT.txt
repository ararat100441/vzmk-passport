4. IMPLEMENTATION
Простой Tk GUI: проект, первый/последний/следующий номер, выбор ВОМ, его итоги,
«Проверить», «Сформировать блок 1». В списке 53 проекта.
Проверка не создаёт паспорт. Формирование работает через Microsoft Excel COM на временных
книгах, копирует первую строку проекта и меняет только номер, массу, дату окончания, соединения.
Формулы сохраняются и пересчитываются существующей Excel-логикой.
Создаётся только Приложение №1; строки ВОМ не объединяются. Таблица имеет нужную длину,
«Итого» находится сразу после данных и вся строка таблицы выделена жирным.
Перед публикацией сохранённые XLSX проверяются на значения, формулы, оформление и итоги.
Есть резервная копия, блокировки, SHA-256 проверки, замена реестра через Windows ReplaceFileW
и журнал состояния. Две файловые сущности не публикуются единой атомарной операцией;
незавершённая операция блокирует повтор и сохраняет резервную копию и временное приложение.

Запуск из Pasport:
powershell -NoProfile -ExecutionPolicy Bypass -File .\Запустить.ps1
Подробности и настройка фактических путей — README.txt.
Для исторических проектов с отличающимися названиями/путями требуется явная настройка;
неоднозначные пути и нестандартные номера блокируют формирование. Полная приёмка всех проектов
не заявляется. Явно настроен и проверен «Гараж Казахстан».
