# ОТЧЁТ CODEX35 — r8

Дата: 31.10.2026, Europe/Samara. **READY_FOR_INDEPENDENT_REVIEW** означает готовность к независимому аудиту кода и кандидата. Это не окончательно принятая рабочая версия и не PRODUCTION READY.

## До остановки Computer Use

В режиме чтения подтверждён корректный остаток контрольной марки: общее количество 1, отгружено 0, остаток 1, требуется 4. История десяти зарегистрированных паспортов и Приложений №1 совпала со справочником. Дублирования истории не обнаружено; сохранённый при миграции исходный ряд также содержит количество 1. Оснований автоматически менять исходные данные нет.

Font Capture / 0xc06d007e воспроизведён в Adobe без запущенного приложения ВЗМК. Первые 15 адресных тестов прошли. После двух дополнений был запущен единственный полный прогон регрессии; Computer Use затем остановил работу из-за невозможности достоверно определить URL окна Edge.

## После возобновления

Прочитан результат уже завершённого прогона: **604 PASS, 0 FAIL, 0 ERROR, 0 SKIP**, включая 17 тестов CODEX35. Второй полный прогон не запускался; исходный код после этого PASS не менялся. Отдельно проверены 17 новых тестов в обезличенном снимке — PASS. Старые фиксированные по датам приёмочные сценарии не выдаются за текущую регрессию.

В актуальной таблице геометрии проверено 975 допустимых строк: групп одинакового профиля и ГОСТ не найдено. Подтверждён скрытый дефект r7: при появлении неодинаковых повторных строк программа брала первую. Теперь сравниваются все размеры, включая радиусы, тип профиля и правило УЗК; численно эквивалентные значения допускаются. При конфликте выдаётся ошибка с номерами всех строк. Первый ГОСТ по порядку, общий выбор профиля и индивидуальные исключения сохранены, в том числе для 120 синтетических марок.

Назначение графического объекта по содержимому DOCX надёжно не определяется. Логотип, схема, техническое изображение, подпись и печать не приравниваются друг к другу. Защитный запрет непроверенных объектов сохранён; сообщение перечисляет документы и объясняет необходимость утверждённого образца. Проверены основная часть, колонтитулы и примечания. Удаления изображений и автоматического переноса старых графических подписей нет. Шесть реальных исходных DOCX двух выбранных серий не содержат таких объектов. На их отдельных копиях проверено 30 добавленных контрольных объектов пяти категорий: все корректно остановлены, копии и оригиналы не изменены проверкой. Безусловный допуск любых логотипов не реализован.

## Frozen EXE, Office, PDF и восстановление

Три нативных сценария нового EXE через `--task`: два разных исходных образца и два вида АКЗ. В каждом пройдены check, prepare, verify, confirm, release, commit, readback, complete. Все данные выпуска — изолированные DEV-копии с синтетическими марками, остатками и измерениями. Структура содержит 16 марок, 28 изделий, план УЗК 4; массы и площади сохранены для проверки реальной структуры. Рабочие книги не пополнялись ради PASS.

Обычный Windows GUI именно r8 также прошёл полный цикл. Ctrl+V ввёл 16 строк; автоматические ГОСТ и четыре плановые единицы УЗК отображались. Диапазоны АКЗ введены через интерфейс. «Нет» отложило выпуск, SHA трёх копий сохранились. После просмотра PDF выполнено одно положительное подтверждение только синтетического DEV-комплекта, согласованная запись трёх файлов, резервные копии, readback и COMPLETE. Последующий GUI recovery восстановил три подготовленные копии по исходным SHA. Дополнительные fault-сценарии проверили откат после каждой из трёх замен, повторный no-op и отказ при внешнем изменении. Повторный commit отклонён без изменения файлов. 76 записей принадлежности Office проверены по PID/времени создания; оставшихся собственных процессов Office нет.

Сравнение постоянных частей Word/Excel с выбранными источниками прошло: значения, стили, формулы, объединения и области печати сохранены вне согласованных переменных полей и пагинации. АКЗ E27/E28 числовые: 130/85 для первого варианта, 170/110 для второго. Итоги строк, количества, массы и площади сверены в XLSX; номера и расчётные даты проверены в документах и PDF.

Финальные PDF нативных сценариев: 9, 9, 11 страниц. Все страницы растрированы Poppler и визуально просмотрены; текст, таблицы и итоги присутствуют, обрезаний не обнаружено. Предварительный GUI-PDF — 9 просмотренных страниц. Финальные 9 страниц GUI побитово совпали по пикселям с уже просмотренным нативным PDF. При четырёх строках контроля блок исполнителя УЗК выходит на отдельную вторую альбомную страницу; это явно оставлено владельцу для оценки оформления. Исходный стиль ради подгонки не изменялся.

## Font Capture и недоступная проверка

Локальный Adobe Acrobat 64-bit 25.1.21208.0 вызывает наблюдаемый диалог и при отдельном открытии контрольного PDF без ВЗМК, и при обычном открытии предварительного PDF из GUI. Системный журнал Application Popup / Event 26 содержит 0xc06d007e; PID CSRSS в событии относится к показу системного сообщения и не доказывает PID сбойного компонента. Дерево процессов Acrobat зафиксировано, но точный дочерний процесс и DLL исключения по доступным журналам не установлены. Ошибка генератора ВЗМК не доказана; Office и PDF-генератор в CODEX35 не менялись. SHA контрольного PDF после просмотра сохранился, независимый разбор и рендер сформированных PDF прошли. Ошибка Font Capture не объявляется устранённой.

**Edge: NOT TESTED.** После остановки Computer Use управление Edge не возобновлялось и не заменялось обходным способом. Результат просмотра в Edge должен получить владелец. Небраузерный GUI ВЗМК был доступен и проверен; отсутствие Edge PASS не скрывается.

## Оставшиеся условия

Реальная отгрузка с недостаточным остатком остаётся заблокированной. Font Capture требует отдельной диагностики Adobe/Windows; точная DLL и дочерний PID не доказаны. Edge остаётся NOT TESTED. Владелец должен независимо принять оформление второй страницы УЗК, исходные формы и достоверность текущего реального контроля. Эти ограничения препятствуют окончательной производственной приёмке, но не скрывают результаты доступных испытаний кандидата. Официальный паспорт реального объекта не выпускался.
