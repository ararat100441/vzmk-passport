Принятый контракт справочника проекта

A Марка | B Профиль | C № АКЗ
Stage 3 импортирует только Марка / Профиль. № АКЗ задаётся вручную,
сохраняется при импорте; у новой марки пуст. Числовой 0 не равен пустому.
Переходный reader допускает legacy: Марка | Профиль | Краска | № АКЗ.
Миграция других проектов не выполняется автоматически.

Будущий Stage 6 (контракт, без реализации генерации)

№ АКЗ — целое неотрицательное число. Пусто — назначение отсутствует.
0: пара шаблонов АКЗ и собственного приложения из первого паспорта проекта;
   акт текущего паспорта без суффикса.
1: пара шаблонов АКЗ-1 и собственного приложения из первого паспорта проекта;
   акт текущего паспорта с суффиксом -1.
2: пара шаблонов АКЗ-2 и собственного приложения из первого паспорта проекта;
   акт текущего паспорта с суффиксом -2.
Для n > 0 действует то же правило суффикса -n.

Все пары шаблонов пользователь самостоятельно размещает в первом паспорте
этого проекта. У каждого варианта своё приложение. Если требуемая пара
отсутствует, STOP соответствующего варианта. Предыдущие паспорта и шаблоны
других проектов не используются. Суффикс не означает количество слоёв.
Материал, RAL, число слоёв и технологические параметры берутся из шаблона.
Генерация АКЗ в этом целевом изменении не реализуется.

Безопасная миграция

passport_app.catalog_migration.migrate_catalog(path, expected_sha): только
явный запуск после текущего assessment и изолированных тестов. Блокировки,
непустая Краска, неверный № АКЗ, сложная неподдержанная структура или новый
SHA останавливают операцию. Backup сохраняется до создания временной книги.
Временная книга проходит normal-load Microsoft Excel read-only, без Save,
до атомарной замены. Никакие реестры модулем миграции не читаются.

rollback_catalog(path, backup, expected_current_sha, expected_backup_sha)
восстанавливает точные исходные байты только при совпадении обоих SHA и
успешном открытии временной копии backup в Excel. Не применять rollback
вслепую после пользовательских изменений. Реальный rollback не запускался.
